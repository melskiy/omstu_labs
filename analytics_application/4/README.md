## 1. Справочник строковых функций SQL

Строковые функции предназначены для манипуляций с текстовыми данными в реляционных базах данных: очистки, преобразования регистра, поиска, конкатенации, извлечения подстрок и форматирования.

| Функция | Назначение | Пример синтаксиса |
| :--- | :--- | :--- |
| `TRIM(str)` | Удаление пробелов в начале и в конце строки | `TRIM('  Эксмо  ')` $\rightarrow$ `'Эксмо'` |
| `LTRIM(str)` / `RTRIM(str)` | Удаление пробелов только слева или только справа | `LTRIM('  Текст')`, `RTRIM('Текст  ')` |
| `LENGTH(str)` / `LEN(str)` | Определение количества символов в строке | `LENGTH('Москва')` $\rightarrow$ `6` |
| `UPPER(str)` / `LOWER(str)` | Преобразование регистра в верхний / нижний | `UPPER('книга')` $\rightarrow$ `'КНИГА'` |
| `INITCAP(str)` | Капитализация: первая буква каждого слова заглавная | `INITCAP('война и мир')` $\rightarrow$ `'Война И Мир'` |
| `LEFT(str, n)` / `RIGHT(str, n)` | Извлечение $N$ символов с начала (слева) или с конца (справа) | `LEFT('7701102233', 2)` $\rightarrow$ `'77'` |
| `SUBSTRING(str FROM pos FOR len)` | Выделение подстроки с позиции `pos` длиной `len` | `SUBSTRING('79991112233' FROM 2 FOR 3)` $\rightarrow$ `'999'` |
| `CONCAT(...)` | Последовательное склеивание строк | `CONCAT('г. ', 'Москва')` $\rightarrow$ `'г. Москва'` |
| `CONCAT_WS(sep, ...)` | Склеивание строк через разделитель `sep` с пропуском `NULL` | `CONCAT_WS(' — ', 'Толстой', 'Война и мир')` |
| `POSITION(sub IN str)` | Поиск индекса первого вхождения подстроки в строку | `POSITION(':' IN 'Война и мир: Том 1')` $\rightarrow$ `12` |
| `REPLACE(str, from, to)` | Замена всех вхождений подстроки `from` на `to` | `REPLACE('г. Москва', 'г. ', 'город ')` |
| `SPLIT_PART(str, delim, idx)` | Извлечение элемента строки по номеру разделителя | `SPLIT_PART('Москва, ул. Ленина', ',', 1)` $\rightarrow$ `'Москва'` |
| `LPAD(str, len, fill)` | Дополнение строки слева символами `fill` до длины `len` | `LPAD('42', 6, '0')` $\rightarrow$ `'000042'` |
| `RPAD(str, len, fill)` | Дополнение строки справа символами `fill` (маскирование) | `RPAD('7999', 11, '*')` $\rightarrow$ `'7999*******'` |
| `STRING_AGG(expr, sep)` | Групповая агрегация строк в единый список через разделитель | `STRING_AGG(Title_book, ', ' ORDER BY Pages DESC)` |

### Пример 1: Очистка и нормализация строк от лишних пробелов (TRIM, LTRIM, RTRIM, LENGTH)

**Бизнес-задача:**  
При импорте справочника издательств пользователи и внешние системы нередко вносят случайные начальные или конечные пробелы. Необходимо:
1. Очистить строки от пробелов с помощью `TRIM()`.
2. Вычислить точное количество паразитных символов через разницу длин `LENGTH(Publish) - LENGTH(TRIM(Publish))`.

#### SQL-запрос:
```sql
SELECT 
    Code_publish,
    Publish AS original_publish,
    LENGTH(Publish) AS len_before,
    LTRIM(Publish) AS left_trimmed,
    RTRIM(Publish) AS right_trimmed,
    TRIM(Publish) AS clean_publish,
    LENGTH(TRIM(Publish)) AS len_after,
    (LENGTH(Publish) - LENGTH(TRIM(Publish))) AS removed_spaces_count
FROM Publishing_house;
```

#### Результат выполнения:
| Code_publish | original_publish | len_before | clean_publish | len_after | removed_spaces_count |
| :---: | :--- | :---: | :--- | :---: | :---: |
| 1 | `'  Питер-Пресс  '` | 15 | `'Питер-Пресс'` | 11 | **4** |
| 2 | `' Эксмо '` | 7 | `'Эксмо'` | 5 | **2** |
| 3 | `'АСТ'` | 3 | `'АСТ'` | 3 | **0** |
| 4 | `'ДМК-Пресс'` | 9 | `'ДМК-Пресс'` | 9 | **0** |
| 5 | `'Наука'` | 5 | `'Наука'` | 5 | **0** |

### Пример 2: Стандартизация регистра текста (UPPER, LOWER, INITCAP)

**Бизнес-задача:**  
Для оформления транспортных документов и почтовых бланков:
1. Перевести тип доставки в верхний регистр (`UPPER`), как принято на транспортных бирках.
2. Привести юридические названия контрагентов к нижнему регистру (`LOWER`) для стандартизированного сопоставления.
3. Отформатировать адрес с капитализацией каждого слова (`INITCAP`).

#### SQL-запрос:
```sql
SELECT 
    Code_delivery,
    Name_delivery,
    UPPER(Name_delivery) AS delivery_type_upper,
    Name_company,
    LOWER(Name_company) AS company_lower,
    Address,
    INITCAP(LOWER(Address)) AS formatted_address
FROM Deliveries;
```

### Пример 3: Извлечение фрагментов строк по краям и позиции (LEFT, RIGHT, SUBSTRING)

**Бизнес-задача:**  
Разбор структурированных реквизитов компаний доставки:
1. Извлечь код региона РФ из ИНН (первые 2 цифры — `LEFT(INN, 2)`).
2. Извлечь последние 4 цифры номера телефона для экспресс-идентификации (`RIGHT(Phone::TEXT, 4)`).
3. Выделить код мобильного оператора (со 2-й цифры, 3 знака — `SUBSTRING(Phone::TEXT FROM 2 FOR 3)`).

### Пример 4: Склеивание строк и конкатенация с разделителем (CONCAT, CONCAT_WS, ||)

**Бизнес-задача:**  
Сформировать единую стандартизированную библиографическую карточку для каталога библиотеки/магазина, объединив автора, название книги, издательство, город издания и количество страниц.  
Функция `CONCAT_WS(' — ', ...)` вставляет разделитель `' — '` между полями и автоматически пропускает пустые/неопределенные значения.

#### SQL-запрос:
```sql
SELECT 
    b.Code_book,
    CONCAT_WS(
        ' — ',
        a.name_author,
        b.Title_book,
        CONCAT(TRIM(p.Publish), ', г. ', TRIM(p.City)),
        b.Pages || ' с.'
    ) AS full_bibliographic_entry
FROM Books b
JOIN Authors a ON b.Code_author = a.Code_author
JOIN Publishing_house p ON b.Code_publish = p.Code_publish
ORDER BY b.Code_book;
```

| 2 | Пушкин А.С. — Сказка о царе Салтане — АСТ, г. Москва — 64 с. |
| 3 | Толстой Л.Н. — Война и мир: Том 1 — Эксмо, г. Москва — 1225 с. |
| 4 | Достоевский Ф.М. — Преступление и наказание — Питер-Пресс, г. Санкт-Петербург — 672 с. |

### Пример 5: Поиск подстроки и замена текста (POSITION, STRPOS, REPLACE)

**Бизнес-задача:**  
Некоторые книги имеют составные названия с подзаголовками через двоеточие (`Война и мир: Том 1`, `Изучаем Python: Руководство`).  
1. С помощью `POSITION(':' IN Title_book)` определить наличие и позицию двоеточия.
2. Выделить только основное название произведения до знака двоеточия.
3. С помощью `REPLACE()` стандартизировать оформление, заменив двоеточие на длинное тире ` -`.

#### SQL-запрос:
```sql
SELECT 
    Code_book,
    Title_book,
    POSITION(':' IN Title_book) AS colon_position,
    CASE 
        WHEN POSITION(':' IN Title_book) > 0 
        THEN SUBSTRING(Title_book FROM 1 FOR POSITION(':' IN Title_book) - 1)
        ELSE Title_book
    END AS main_title_only,
    REPLACE(Title_book, ':', ' -') AS title_with_dash
FROM Books;
```

#### Результат выполнения:
| Code_book | Title_book | colon_position | main_title_only | title_with_dash |
| :---: | :--- | :---: | :--- | :--- |
| 1 | Капитанская дочка | 0 | Капитанская дочка | Капитанская дочка |
| 2 | Сказка о царе Салтане | 0 | Сказка о царе Салтане | Сказка о царе Салтане |
| 3 | Война и мир: Том 1 | **12** | **Война и мир** | Война и мир - Том 1 |
| 4 | Преступление и наказание | 0 | Преступление и наказание | Преступление и наказание |
| 5 | Изучаем Python: Руководство | **15** | **Изучаем Python** | Изучаем Python - Руководство |
| 6 | PostgreSQL 16: Базовый курс | **14** | **PostgreSQL 16** | PostgreSQL 16 - Базовый курс |
| 7 | 1984 | 0 | 1984 | 1984 |

### Пример 6: Разделение строк и форматирование с заполнением (SPLIT_PART, LPAD, RPAD)

**Бизнес-задача:**  
1. **Парсинг адреса:** извлечь отдельно название города (`SPLIT_PART(Address, ',', 1)`) и улицу (`SPLIT_PART(Address, ',', 2)`).
2. **Генерация штрихкода:** дополнить целочисленный идентификатор доставки слева нулями до фиксированной ширины в 6 символов (`LPAD(Code, 6, '0')`).
3. **Безопасность ПДн (Маскирование):** отобразить только первые 4 цифры телефона клиента, заполнив оставшиеся 7 позиций звездочками (`RPAD(LEFT(Phone, 4), 11, '*')`).

#### SQL-запрос:
```sql
SELECT 
    Code_delivery,
    LPAD(Code_delivery::TEXT, 6, '0') AS padded_barcode_id,
    Address,
    TRIM(SPLIT_PART(Address, ',', 1)) AS city_extracted,
    TRIM(SPLIT_PART(Address, ',', 2)) AS street_extracted,
    RPAD(LEFT(Phone::TEXT, 4), 11, '*') AS masked_safe_phone
FROM Deliveries;
```

### Пример 7: Групповая агрегация строк в единый перечень (STRING_AGG с сортировкой)

**Бизнес-задача:**  
Сформировать сводный реестр авторов для издательского каталога:
- Подсчитать суммарное количество изданных книг каждого автора (`COUNT(*)`);
- Объединить названия всех книг каждого автора в единую форматированную текстовую строку через точку с запятой, упорядочив книги внутри строки по убыванию объема страниц: `STRING_AGG(CONCAT(Title, ' (', Pages, ' с.)'), '; ' ORDER BY Pages DESC)`.

#### SQL-запрос:
```sql
SELECT 
    a.Code_author,
    a.name_author,
    COUNT(b.Code_book) AS total_books_count,
    STRING_AGG(
        CONCAT(b.Title_book, ' (', b.Pages, ' с.)'), 
        '; ' 
        ORDER BY b.Pages DESC
    ) AS catalog_of_books
FROM Authors a
JOIN Books b ON a.Code_author = b.Code_author
GROUP BY a.Code_author, a.name_author
ORDER BY total_books_count DESC, a.name_author;
```

#### Результат выполнения:
| Code_author | name_author | total_books_count | catalog_of_books |
| :---: | :--- | :---: | :--- |
| 1 | **Пушкин А.С.** | 2 | Капитанская дочка (320 с.); Сказка о царе Салтане (64 с.) |
| 4 | **Стивен Кинг** | 2 | Изучаем Python: Руководство (800 с.); PostgreSQL 16: Базовый курс (560 с.) |
| 2 | **Толстой Л.Н.** | 1 | Война и мир: Том 1 (1225 с.) |
| 3 | **Достоевский Ф.М.** | 1 | Преступление и наказание (672 с.) |
| 5 | **Джордж Оруэлл** | 1 | 1984 (328 с.) |
